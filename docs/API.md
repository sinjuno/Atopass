# 기능명세서 v1.0

## 1. 회원/인증

| 기능 ID | 기능명 | 입력 | 처리 | 출력 | 설명 |
| --- | --- | --- | --- | --- | --- |
| AUTH-01 | 회원가입 | 이메일, 비밀번호 등 | 입력값 검증 후 회원 정보 저장 | 회원가입 결과 | 새로운 사용자 계정을 생성한다. |
| AUTH-02 | 로그인 | 이메일, 비밀번호 | 사용자 인증 및 JWT 발급 | 로그인 결과, JWT | 등록된 사용자의 로그인을 처리한다. |
| AUTH-03 | 로그아웃 | 인증 정보 | 인증 상태 종료 | 로그아웃 결과 | 현재 사용자의 로그인을 종료한다. |
| AUTH-04 | 사용자 인증 | JWT | 토큰 검증 | 인증된 사용자 정보 | API 요청 사용자의 인증 상태를 확인한다. |
| AUTH-05 | 사용자 권한 확인 | 사용자 ID, 데이터 ID | 소유권 확인 | 접근 허용/거부 | 자신의 기록에만 접근할 수 있도록 확인한다. |

## 2. 피부 기록

| 기능 ID | 기능명 | 설명 | 입력 | 처리 | 출력 |
| --- | --- | --- | --- | --- | --- |
| REC-01 | 피부 기록 작성 | 사용자가 피부 상태를 기록한다. | 피부 부위, 증상, 점수 등 | 입력값 검증 후 기록 생성 | 저장 결과 |
| REC-02 | 증상 기록 | 피부 증상을 기록한다. | 가려움, 따가움, 붉은기, 건조함, 각질, 부어오름, 통증 등 | 증상 및 점수 저장 | 증상 기록 |
| REC-03 | 증상 점수 입력 | 사용자가 느끼는 증상의 정도를 1~5로 기록한다. | 증상별 점수 | 점수 검증 후 저장 | 점수 기록 |
| REC-04 | 피부 사진 등록 | 피부 상태 사진을 기록용으로 저장한다. | 이미지 파일 | 파일 검증 및 저장 | 사진 저장 결과 |
| REC-05 | 수면 기록 | 사용자의 수면 정보를 기록한다. | 수면 시간 | 입력값 검증 후 저장 | 수면 기록 |
| REC-06 | 생활습관 기록 | 음주, 외출 등 생활 정보를 기록한다. | 생활습관 정보 | 기록 데이터 저장 | 생활습관 기록 |
| REC-07 | 특이사항 기록 | 사용자가 추가적인 내용을 기록한다. | 텍스트 | 내용 저장 | 특이사항 |
| REC-08 | 날짜별 기록 조회 | 특정 날짜의 기록을 조회한다. | 날짜 | 해당 사용자의 기록 조회 | 날짜별 기록 |
| REC-09 | 기록 수정 | 기존에 저장한 기록을 수정한다. | 기록 ID, 수정 내용 | 사용자 권한 확인 후 수정 | 수정 결과 |
| REC-10 | 기록 삭제 | 기존 기록을 삭제한다. | 기록 ID | 사용자 권한 확인 후 삭제 | 삭제 결과 |

| --- | --- | --- | --- | --- | --- |

| CHAT-08 | 과거 기록 질문 | 사용자가 자신의 과거 기록에 대해 질문한다. | 자연어 질문 | 관련 기록 조회 및 분석 | 답변 |

| CHAT-10 | 개인 변화 질문 | 사용자의 평소 기록과 최근 기록의 차이를 질문한다. | 자연어 질문 | 개인 기록 기반 분석 | 자연어 분석 결과 |
